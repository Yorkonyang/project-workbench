快速开始

1. 启动后端服务器 
cd server
npm install
node scripts/init-db.js
npm start
2. 前端连接配置 
# 在项目根目录创建 .env 文件
echo "VITE_API_URL=http://localhost:3000/api" > .env
3. 启动前端开发服务器 
npm run dev

数据迁移指南

从 localStorage 迁移到 SQLite
  1. 在浏览器控制台运行 exportAllData() 导出数据
  2. 将导出的 JSON 文件放入 server/migration-data/ 目录
  3. 重命名文件为表名: projects.json, tasks.json 等
  4. 运行迁移脚本: node scripts/migrate.js
