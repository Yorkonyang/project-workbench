## 1. 系统概述

项目工作台是一个集成的项目管理平台，支持以下核心功能：

- **项目管理**：创建、编辑、归档、合并项目，跟踪项目进度；支持多级子项目（最多 4 个层级）
- **任务管理**：创建任务、分配多个责任人、汇报进度、关联待办
- **待办管理**：为任务添加待办事项，跟踪完成情况
- **文档管理**：上传和关联项目文档
- **里程碑跟踪**：记录项目关键节点
- **时间线 / 甘特图**：可视化项目与任务排期，按项目族色区分主项目与子项目
- **通知提醒**：任务到期提醒、待办逾期预警

### 访问地址

- 本地访问：http://localhost:5173
- 局域网访问：http://<本机IP>:5173（如 http://172.17.31.28:5173）

## 3. 创建项目

### 操作路径

**首页** → 点击"新建项目"按钮  
或  
**左侧菜单** → "项目管理" → 右上角"+ 新建项目"

### 填写项目信息

创建项目时需要填写以下字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 项目编号 | 是 | 唯一标识。主项目形如 `XM_008`，系统自动递增生成，一般无需手工输入 |
| 项目名称 | 是 | 项目的正式名称 |
| 所属项目类型 | 否 | 从数据字典中选择，如"研发项目"、"管理系统"等 |
| 项目阶段 | 否 | 如"规划中"、"进行中"、"已完成"等 |
| 隶属项目 | 否 | 如为子项目，选择上级项目（详见第 4 节） |
| 负责人 | 否 | 指定项目负责人（owner） |
| 成员 | 否 | 选择参与项目的成员（支持多选） |
| 开始日期 | 否 | 项目启动日期 |
| 结束日期 | 否 | 项目计划完成日期 |
| 项目描述 | 否 | 项目的背景和目标说明 |
| 项目颜色 | 是 | 选择项目主题色（用于区分不同项目；子项目会自动继承主项目色系） |

### 提交保存

填写完成后点击"提交"按钮，项目创建成功。

### 项目创建后的操作

创建项目后，您可以：

1. **查看项目详情**：点击项目卡片进入详情页
2. **添加任务**：在项目详情页的"任务"Tab 中添加任务
3. **添加待办**：在项目详情页的"待办"Tab 中添加待办事项
4. **添加文档**：在项目详情页的"文档"Tab 中上传项目文档
5. **设置里程碑**：在项目详情页的"里程碑"Tab 中记录关键节点
6. **新建子项目**：在项目详情页右上角点击"新建子项目"（见第 4 节）
7. **合并项目**：在项目详情页右上角点击"合并到…"（见第 5 节）

## 4. 多级子项目

项目支持最多 4 个层级的子项目结构（主项目 + 3 级子项目）。

### 层级与编号规则

子项目自动继承主项目的编号，并在后面追加单数字序号：

```
XM_008（主项目）
└── XM_008.1（一级子项目）
    └── XM_008.1.1（二级子项目）
```

- **主项目**：编号形如 `XM_008`，由系统按全局序号递增生成
- **一级子项目**：编号 = 主项目编号 + `.` + 同级序号（单数字），如 `XM_008.1`、`XM_008.2`
- **二级子项目**：在一级子项目编号后再加一级，如 `XM_008.1.1`
- 层级深度上限：根（level 0）+ 最多 4 层子孙 = 5 个展示层级；达到上限后无法再建更深层子项目

### 操作步骤

**在某个项目下新建子项目：**

1. 进入目标项目详情页
2. 点击右上角"新建子项目"
3. 系统自动填充：
   - **隶属项目**：锁定为当前项目（不可改为其他项目）
   - **项目编号**：自动按"父编号.序号"规则生成，无需手填
   - **项目颜色**：继承主项目色系（子项目按层级自动变浅，见第 9 节）
4. 填写名称、负责人、成员、日期等字段后提交

**在项目管理页批量管理子项目：**

- 左侧菜单 → "项目管理"：项目以"项目 → 任务 → 待办"折叠视图展示，子项目缩进显示层级

### 注意事项

- 子项目与主项目遵循相同的权限模型（项目负责制，见附录），子项目的权限随其所属主项目链继承
- 修改"隶属项目"时，系统会自动重新计算该项目的层级编号
- 子项目下同样可以建任务、待办、文档、里程碑

## 5. 项目合并与撤销

当存在重复或需归并的项目时，可将"源项目"整树并入"目标项目"。

### 操作步骤

1. 进入**源项目**详情页
2. 点击右上角"合并到…"
3. 在弹窗中：
   - **选择目标项目**：候选树已排除自身、自身的子孙、已归档与已合并的项目
   - **预览合并影响**：选中目标后点击"预览合并影响"，查看哪些任务/待办/文档/里程碑/风险/资源将随源项目归属目标
   - **选择合并策略**：
     - **保留层级（keep）**：源项目的子项目改挂到目标项目下，保留各自层级
     - **拍平（flatten）**：源项目整棵子树直接挂到目标项目下，丢弃中间层级
   - **勾选强确认**后点击"确认合并"
4. 合并成功后跳转到目标项目详情页；源项目被软隐藏（带"已合并到 X"提示，不再出现在任何列表）

### 撤销合并（24 小时限时）

合并后**源项目的 24 小时内**可在目标项目一键撤销：

1. 进入目标项目详情页
2. 页面顶部显示"已并入本项目的子项目（24h 内可撤销）"横幅
3. 点击对应源项目的"撤销"按钮
4. 源项目恢复独立，被并入的任务/待办/文档/里程碑/风险/资源会重新归属回源项目

### 注意事项

- 合并是不可逆的强操作（强确认），但 24 小时内的撤销窗口可兜底回滚
- 超过 24 小时后撤销入口消失，数据将保持已合并状态
- 合并目标若与源项目层级冲突（如会超出 4 层上限或编号碰撞），预览阶段会给出警告

## 6. 为项目添加任务

### 操作路径

**方式一：从项目详情页添加**
1. 进入目标项目详情页
2. 点击"任务"Tab
3. 点击"+ 新增"按钮

**方式二：从任务管理页面添加**
1. 左侧菜单 → "任务管理"
2. 右上角"+ 新建任务"按钮

### 填写任务信息

任务表单包含以下字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 项目名称 | 自动填充 | 新建任务时会自动填充所属项目；项目管理页/任务管理页的下拉默认只列出主项目，勾选"含子项目"后才展开子项目 |
| 任务标题 | 是 | 任务名称，简洁明了 |
| 任务描述 | 否 | 详细描述任务内容和要求 |
| 责任人 | 是 | 选择负责执行任务的成员（支持多选，可分配给多人） |
| 优先级 | 否 | 高/中/低，影响任务显示顺序 |
| 状态 | 自动 | 新建任务默认为"待办"状态 |
| 开始日期 | 否 | 任务计划开始时间 |
| 截止日期 | 否 | 任务应完成的时间 |
| 标签 | 否 | 用逗号分隔添加标签，如 `前端, urgent` |

### 多责任人说明

- 一个任务可同时分配给**多名责任人**（`assignees` 多选）
- 所有被分配的责任人都能在"任务管理"页看到该任务，并各自汇报进度
- 通知提醒会同时发送给全部责任人
- 兼容旧数据：早期单责任人任务（`assignee` 字段）仍正常显示

### 提交任务

点击"提交"按钮，任务创建成功。

### 任务状态流转

任务有以下几种状态，可按照流程推进：

```
待办 → 进行中 → 评审中 → 已完成
            ↓
          已阻塞（中途可标记）
```

**状态说明：**

| 状态 | 说明 | 操作权限 |
|------|------|----------|
| 待办 | 任务已创建，等待执行 | 负责人可启动 |
| 进行中 | 任务正在执行中 | 负责人可汇报进度、提交评审 |
| 评审中 | 任务已完成并提交评审 | 管理员可评审通过/驳回 |
| 已完成 | 任务评审通过，正式完成 | - |
| 已阻塞 | 任务因某种原因暂停 | 负责人可解除阻塞 |

### 任务进度汇报

作为任务负责人，您可以：

1. **启动任务**：点击"启动任务"按钮，任务进入"进行中"状态
2. **汇报进度**：
   - 点击任务卡片进入进度汇报页
   - 填写本次工作进展内容
   - 提交汇报记录
3. **提交评审**：任务完成后，点击"提交审核"
4. **撤回提交**：评审中可撤回重新修改

2. 右上角"+ 新建待办"按钮

待办表单包含以下字段：

| 字段 | 必填 | 说明 |
|------|------|------|

| 描述 | 否 | 详细说明待办内容和要求 |

点击"提交"按钮，待办创建成功。

### 待办管理功能

**负责人可以：**
- ✅ 勾选完成待办（点击左侧复选框）
- 📝 编辑待办内容
- 🗑️ 删除待办（如有权限）

**系统自动：**
- ⏰ 逾期自动标红提醒
- 🔔 到期前发送通知提醒
- 📊 自动统计完成情况

### 待办与任务的关系

- 待办可关联到具体任务
- 任务完成时，其下属所有待办自动归档
- 待办可独立存在（不关联任务），适合个人任务跟踪

## 8. 添加项目文档

2. 右上角"+ 新建文档"按钮

### 文档上传方式

系统支持两种文档录入方式：

#### 方式一：关联已有文档库文档

1. 点击"添加文档"
2. 在弹出窗口中搜索文档（支持按标题搜索）

#### 方式二：新建文档记录

1. 点击"添加文档"

3. 填写文档信息：
   - **文档标题**：文档名称
   - **分类**：选择文档类型（需求文档、设计文档、会议纪要等）
   - **所属项目**：自动关联当前项目
   - **描述**：文档说明

   - **附件**：上传文档文件（支持 PDF、Word、Excel、PPT 等）

**查看文档：**
- 点击文档标题跳转到文档详情
- 下载附件文件

**编辑文档：**

**删除文档：**
- 点击"删除"按钮移除文档（需有权限）
- 文档删除后无法恢复，请谨慎操作

### 文档分类说明

| 分类 | 说明 |
|------|------|
| 需求文档 | 项目需求分析、功能规格说明书 |

| 会议纪要 | 项目会议记录 |
| 验收报告 | 项目验收相关文档 |
| 计划报告 | 项目计划、进度报告 |
| 其他 | 不属于上述分类的文档 |

## 9. 时间线与甘特图

左侧菜单 → "时间线"（或项目详情页"里程碑"Tab 关联的甘特视图）可直观查看项目与任务的排期。

### 项目筛选

- 顶部"选择项目"下拉框**默认只列出主项目**（编号 `XM_NNN` 在前、项目名在后）
- 勾选"**含子项目**"后，下拉才会展开子项目（`XM_NNN.1`、`XM_NNN.1.1`）
- 选中某主项目时，甘特图会展示该主项目及其子项目树（collectSubtree）

### 项目族色规则

- 每个主项目分配一个**色系**（4 色轮转：灰蓝 / 翠绿 / 蓝 / 琥珀）
- 其下属子项目**继承主项目色系**，并按层级自动变浅：
  - 主项目标题底色 = 该色系最深档
  - 一级子项目标题底色 = 第二深档
  - 二级子项目标题底色 = 第三深档
  - 三级子项目标题底色 = 最浅档
- 肉眼可分辨"越深越浅"的层级差异，且最浅档也深于任务底色，不会混淆

### 任务行底色（交替）

- 同一主项目内部的任务行**按行号交替**底色：
  - 第 1 个任务：白色
  - 第 2 个任务：该主项目色系最浅档（约 30% 深度）
  - 第 3 个任务：白色
  - 以此类推
- 目的是让连续任务在甘特图上有节奏感，同时与项目标题底色区分开

### 左侧标签栏宽度

- 甘特图左侧"项目 / 任务"标签栏**宽度自适应**：根据当前视图中最长的项目/任务/里程碑标题自动加宽，保证完整显示不换行（有上下限约束）
- 子项目标签按层级缩进，层级越深缩进越多

### 空子项目

- 没有任务/里程碑的空子项目，也会显示一条"汇总行"（带项目族色底色），便于看出层级结构

## 10. 常见问题

### Q1：登录后看不到某些功能？

**原因**：权限不足。

**解决**：
- "提醒设置"和"组织架构"：仅管理员可见
- "数据字典"：管理员、项目负责人、项目成员均可见
- 如需更高权限，请联系系统管理员

### Q2：任务推送的链接打不开？

**原因**：前端访问地址配置错误。

**解决**：
1. 进入"提醒设置"页面
2. 找到"BPM 集成"配置项
3. 将"前端访问地址"修改为实际可访问的地址（如 http://172.17.31.28:5173）
4. 重新触发推送

### Q3：同任务多责任人，谁先点开链接谁登录？

**机制**：SSO 链接使用 HMAC 签名，链接中不包含邮箱明文。责任人点击链接后自动登录，无需手动输入账号密码。

### Q4：如何批量导入成员？

**方式**：使用"组织架构与成员"页面的 Excel 导入功能，按模板格式填写成员信息后上传。

### Q5：项目归档后还能恢复吗？

**可以**。项目负责人可申请归档，归档后项目变为只读状态。如需恢复，管理员可在审批通过后将项目恢复为正常状态。

### Q6：子项目的时间线为什么在主项目下拉里看不到？

**原因**：项目下拉框默认只列出主项目，子项目需展开。

**解决**：
1. 进入"时间线"页（或"任务管理"页）
2. 在"选择项目"下拉框勾选"**含子项目**"
3. 子项目（`XM_NNN.1`、`XM_NNN.1.1`）即会出现在下拉选项中

### Q7：甘特图里同一主项目的子项目颜色为什么有深有浅？

**这是设计**：子项目继承主项目的色系，并按层级自动变浅（主项目最深 → 一级 → 二级 → 三级最浅），方便肉眼分辨层级。任务行底色则在白色与"该色系最浅档（约 30%）"之间交替，与项目标题底色区分开。

### Q8：合并项目后反悔了怎么办？

**可在 24 小时内撤销**：
1. 进入合并的**目标项目**详情页
2. 顶部出现"已并入本项目的子项目（24h 内可撤销）"横幅
3. 点击对应源项目的"撤销"，源项目恢复独立、数据重新归属回源项目
4. 超过 24 小时后撤销入口消失，数据保持已合并状态

### Q9：一个任务被分配给多人，谁能汇报进度？

**所有被分配的责任人都可以**：每位责任人都能在"任务管理"页看到该任务并各自汇报进度；到期提醒会同时发送给全部责任人。
