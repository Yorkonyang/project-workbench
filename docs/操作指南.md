## 1. 系统概述

项目工作台是一个集成的项目管理平台，支持以下核心功能：

- **项目管理**：创建、编辑、归档项目，跟踪项目进度
- **任务管理**：创建任务、分配责任人、汇报进度、关联待办
- **待办管理**：为任务添加待办事项，跟踪完成情况
- **文档管理**：上传和关联项目文档
- **里程碑跟踪**：记录项目关键节点
- **通知提醒**：任务到期提醒、待办逾期预警

### 访问地址

- 本地访问：http://localhost:5173
- 局域网访问：http://<本机IP>:5173（如 http://172.17.31.28:5173）

## 2. 登录系统

### 步骤

1. 打开浏览器，输入访问地址
2. 在登录页面输入：
   - **邮箱**：管理员提供的账号（如 yyg@grikin.com）
   - **密码**：初始密码（首次登录建议修改）
3. 点击"登录"按钮
4. 登录成功后进入首页仪表盘

### 管理员账号（默认）

| 角色 | 邮箱 | 说明 |
|------|------|------|
| 管理员 | admin@grikin.com | 拥有所有权限，可管理成员、组织架构、数据字典 |
| 普通成员 | （由管理员创建） | 仅可见分配给自己的任务 |

## 3. 创建项目

### 操作路径

**首页** → 点击"新建项目"按钮  
或  
**左侧菜单** → "项目管理" → 右上角"+ 新建项目"

### 填写项目信息

创建项目时需要填写以下字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 项目编号 | 是 | 唯一标识，如 `XM-2026-001`，系统自动生成但可自定义 |
| 项目名称 | 是 | 项目的正式名称 |
| 所属项目类型 | 否 | 从数据字典中选择，如"研发项目"、"管理系统"等 |
| 项目阶段 | 否 | 如"规划中"、"进行中"、"已完成"等 |
| 父项目 | 否 | 如为子项目，选择上级项目 |
| 负责人 | 否 | 指定项目负责人 |
| 成员 | 否 | 选择参与项目的成员（支持多选） |
| 开始日期 | 否 | 项目启动日期 |
| 结束日期 | 否 | 项目计划完成日期 |
| 项目描述 | 否 | 项目的背景和目标说明 |
| 项目颜色 | 是 | 选择项目主题色（用于区分不同项目） |

### 提交保存

填写完成后点击"提交"按钮，项目创建成功。

### 项目创建后的操作

创建项目后，您可以：

1. **查看项目详情**：点击项目卡片进入详情页
2. **添加任务**：在项目详情页的"任务"Tab 中添加任务
3. **添加待办**：在项目详情页的"待办"Tab 中添加待办事项
4. **添加文档**：在项目详情页的"文档"Tab 中上传项目文档
5. **设置里程碑**：在项目详情页的"里程碑"Tab 中记录关键节点

## 4. 为项目添加任务

### 操作路径

**方式一：从项目详情页添加**
1. 进入目标项目详情页
2. 点击"任务"Tab
3. 点击"+ 新增"按钮

**方式二：从任务管理页面添加**
1. 左侧菜单 → "任务管理"
2. 右上角"+ 新建任务"按钮

### 填写任务信息

任务表单包含以下字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 项目名称 | 自动填充 | 新建任务时会自动填充所属项目 |
| 任务标题 | 是 | 任务名称，简洁明了 |
| 任务描述 | 否 | 详细描述任务内容和要求 |
| 责任人 | 是 | 选择负责执行任务的成员（支持多选） |
| 优先级 | 否 | 高/中/低，影响任务显示顺序 |
| 状态 | 自动 | 新建任务默认为"待办"状态 |
| 开始日期 | 否 | 任务计划开始时间 |
| 截止日期 | 否 | 任务应完成的时间 |
| 标签 | 否 | 用逗号分隔添加标签，如 `前端, urgent` |

### 提交任务

点击"提交"按钮，任务创建成功。

### 任务状态流转

任务有以下几种状态，可按照流程推进：

```
待办 → 进行中 → 评审中 → 已完成
            ↓
          已阻塞（中途可标记）
```

**状态说明：**

| 状态 | 说明 | 操作权限 |
|------|------|----------|
| 待办 | 任务已创建，等待执行 | 负责人可启动 |
| 进行中 | 任务正在执行中 | 负责人可汇报进度、提交评审 |
| 评审中 | 任务已完成并提交评审 | 管理员可评审通过/驳回 |
| 已完成 | 任务评审通过，正式完成 | - |
| 已阻塞 | 任务因某种原因暂停 | 负责人可解除阻塞 |

### 任务进度汇报

作为任务负责人，您可以：

1. **启动任务**：点击"启动任务"按钮，任务进入"进行中"状态
2. **汇报进度**：
   - 点击任务卡片进入进度汇报页
   - 填写本次工作进展内容
   - 提交汇报记录
3. **提交评审**：任务完成后，点击"提交审核"
4. **撤回提交**：评审中可撤回重新修改

## 5. 添加待办事项

### 操作路径

**方式一：从项目详情页添加**
1. 进入目标项目详情页
2. 点击"待办"Tab
3. 点击"+ 新增"按钮

**方式二：从待办管理页面添加**
1. 左侧菜单 → "待办管理"
2. 右上角"+ 新建待办"按钮

**方式三：从任务详情页添加**
1. 进入任务进度汇报页
2. 左侧"关联待办"区域点击"新增待办"

### 填写待办信息

待办表单包含以下字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | 是 | 待办事项名称 |
| 描述 | 否 | 详细说明待办内容和要求 |
| 所属项目 | 否 | 选择归属项目（关联待办会自动关联项目） |
| 关联任务 | 否 | 关联到具体任务，便于追踪 |
| 负责人 | 否 | 指定执行人 |
| 截止日期 | 否 | 待办应完成的时间 |
| 优先级 | 否 | 高/中/低 |
| 提醒设置 | 否 | 是否开启提醒、提前几天提醒 |

### 提交待办

点击"提交"按钮，待办创建成功。

### 待办管理功能

**负责人可以：**
- ✅ 勾选完成待办（点击左侧复选框）
- 📝 编辑待办内容
- 🗑️ 删除待办（如有权限）

**系统自动：**
- ⏰ 逾期自动标红提醒
- 🔔 到期前发送通知提醒
- 📊 自动统计完成情况

### 待办与任务的关系

- 待办可关联到具体任务
- 任务完成时，其下属所有待办自动归档
- 待办可独立存在（不关联任务），适合个人任务跟踪

## 6. 添加项目文档

### 操作路径

**方式一：从项目详情页添加**
1. 进入目标项目详情页
2. 点击"文档"Tab
3. 点击右上角"+ 添加文档"按钮

**方式二：从文档管理页面添加**
1. 左侧菜单 → "文档管理"
2. 右上角"+ 新建文档"按钮

### 文档上传方式

系统支持两种文档录入方式：

#### 方式一：关联已有文档库文档

1. 点击"添加文档"
2. 在弹出窗口中搜索文档（支持按标题搜索）
3. 勾选要关联的文档
4. 点击"完成关联"按钮

#### 方式二：新建文档记录

1. 点击"添加文档"
2. 在弹出窗口中点击"新建文档"按钮
3. 填写文档信息：
   - **文档标题**：文档名称
   - **分类**：选择文档类型（需求文档、设计文档、会议纪要等）
   - **所属项目**：自动关联当前项目
   - **描述**：文档说明
   - **标签**：用逗号分隔的标签
   - **附件**：上传文档文件（支持 PDF、Word、Excel、PPT 等）
4. 点击"提交"按钮

### 文档管理功能

**查看文档：**
- 点击文档标题跳转到文档详情
- 下载附件文件

**编辑文档：**
- 点击"编辑"按钮修改文档信息
- 可替换附件文件

**删除文档：**
- 点击"删除"按钮移除文档（需有权限）
- 文档删除后无法恢复，请谨慎操作

### 文档分类说明

系统内置以下文档分类：

| 分类 | 说明 |
|------|------|
| 需求文档 | 项目需求分析、功能规格说明书 |
| 设计文档 | 系统设计、技术架构文档 |
| 会议纪要 | 项目会议记录 |
| 验收报告 | 项目验收相关文档 |
| 计划报告 | 项目计划、进度报告 |
| 其他 | 不属于上述分类的文档 |

## 7. 常见问题

### Q1：登录后看不到某些功能？

**原因**：权限不足。

**解决**：
- "提醒设置"和"组织架构"：仅管理员可见
- "数据字典"：仅项目负责人可见
- 如需更高权限，请联系系统管理员

### Q2：任务推送的链接打不开？

**原因**：前端访问地址配置错误。

**解决**：
1. 进入"提醒设置"页面
2. 找到"BPM 集成"配置项
3. 将"前端访问地址"修改为实际可访问的地址（如 http://172.17.31.28:5173）
4. 重新触发推送

### Q3：同任务多责任人，谁先点开链接谁登录？

**机制**：SSO 链接使用 HMAC 签名，链接中不包含邮箱明文。责任人点击链接后自动登录，无需手动输入账号密码。

### Q4：如何批量导入成员？

**方式**：使用"组织架构与成员"页面的 Excel 导入功能，按模板格式填写成员信息后上传。

### Q5：项目归档后还能恢复吗？

**可以**。项目负责人可申请归档，归档后项目变为只读状态。如需恢复，管理员可在审批通过后将项目恢复为正常状态。
