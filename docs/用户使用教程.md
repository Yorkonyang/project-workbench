## 快速开始

### 系统要求
- 现代浏览器（Chrome、Edge、Firefox、Safari）
- 稳定的网络连接

### 启动方式

**本地开发环境**：
```bash
# 后端
cd server
node simple-server.js

# 前端（新终端）
cd D:\AI\project-workbench
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5173
```

**生产环境**：
```bash
cd ~/xmgl/project-workbench
bash scripts/server-run.sh
```

访问：http://localhost:5173（本地）/ http://172.17.80.141:5173（服务器）

## 登录系统

### 方式一：SSO 登录（推荐）

1. 点击登录页的"企微登录"按钮
2. 跳转到企业微信授权页面
3. 授权后自动跳转回系统，完成登录

**优点**：
- 无需记忆密码
- 自动同步企业成员信息
- 安全性高（HttpOnly Cookie）

### 方式二：账号密码登录

1. 输入企业微信账号（邮箱）
2. 输入密码
3. 点击"登录"

**注意**：
- 密码由管理员在"成员管理"页面设置
- 首次登录后建议修改密码

## 仪表盘

### 功能概览

仪表盘是系统的首页，提供以下核心信息：

| 统计项 | 说明 |
|--------|------|
| **任务总数** | 项目中所有任务的数量（含完成/未完成） |
| **待达成里程碑** | 状态为 upcoming 或 at_risk 的里程碑数量 |
| **待处理风险** | 状态非 closed 的风险数量 |
| **团队成员** | 被分配任务或待办的人员去重计数 |
| **未完成事项** | 进行中任务 + 待启动任务 + 未完成待办 |

### 快捷操作

- 点击"未完成事项"卡片 → 跳转到待办与提醒页面
- 点击"团队成员"卡片 → 跳转到成员管理页面
- 点击"项目统计"卡片 → 查看各项目进度
- 点击"任务状态图表" → 查看任务分布
- 点击"进度对比" → 查看项目完成率对比

## 项目管理

### 项目列表

访问路径：`/projects`

**功能**：
- 查看所有项目（按创建时间倒序）
- 搜索项目（按项目名称）
- 创建新项目
- 查看项目详情
- 归档项目（需审批）

### 创建项目

1. 点击右上角"新建项目"按钮
2. 填写项目信息：
   - **项目名称**：必填，项目标识
   - **项目类型**：从字典中选择（如"研发项目"、"市场活动"）
   - **项目阶段**：从字典中选择（如"规划中"、"执行中"、"已交付"）
   - **负责人**：必填，项目所有者
   - **项目描述**：选填，项目背景和目标
3. 点击"创建"

**注意**：
- 负责人必须是系统成员
- 创建后自动生成项目编号（XM_xxx）

### 项目详情

访问路径：`/projects/:id`

**功能模块**：

#### 1. 基本信息
- 项目名称、编号、类型、阶段
- 负责人、创建时间、归档状态
- 项目描述

#### 2. 任务时间线
- 查看任务列表（按截止日期排序）
- 添加任务、编辑任务、删除任务
- 任务进度汇报
- 任务状态：待启动 → 进行中 → 评审中 → 已完成/已阻塞

#### 3. 里程碑
- 查看里程碑列表
- 添加里程碑、编辑里程碑、删除里程碑
- 里程碑状态：upcoming（即将到来）、active（进行中）、at_risk（有风险）、completed（已完成）

#### 4. 风险
- 查看风险列表
- 添加风险、编辑风险、删除风险
- 风险等级：低（1-3）、中（4-6）、高（7-10）
- 风险状态：open（未处理）、in_progress（处理中）、closed（已关闭）

#### 5. 文档
- 查看项目文档列表
- 上传文档、编辑文档、删除文档
- 文档类型：技术文档、会议纪要、需求文档、其他

#### 6. 资源
- 查看项目资源列表
- 添加资源、编辑资源、删除资源
- 资源类型：人力、设备、资金、其他

### 项目归档审批

**触发条件**：
- 项目负责人发起归档申请
- 管理员审批通过

**流程**：

1. **项目负责人**：
   - 进入项目详情页
   - 点击右上角"归档项目"按钮
   - 填写归档原因
   - 提交申请

2. **管理员审批**：
   - 进入"项目管理"页面
   - 找到待审批项目
   - 点击"审批"按钮
   - 选择"通过"或"驳回"
   - 如果通过，项目归档；如果驳回，项目恢复

3. **项目归档后**：
   - 项目不在项目列表中显示
   - 项目相关数据（任务/文档/风险）仍然保留
   - 如需恢复，需管理员手动操作

## 任务管理

### 任务列表

访问路径：`/tasks`

**视图切换**：
- **看板视图**：按状态分列（待启动、进行中、评审中、已完成、已阻塞）
- **列表视图**：按时间排序，显示更多字段

**功能**：
- 搜索任务（按任务名称、项目名称）
- 筛选任务（按项目、状态、负责人）
- 创建任务
- 查看任务详情
- 任务进度汇报
- 任务编辑/删除（仅负责人）

### 创建任务

1. 点击右上角"新建任务"按钮
2. 填写任务信息：
   - **项目**：必填，任务所属项目
   - **任务名称**：必填，任务标识
   - **任务描述**：选填，任务详细说明
   - **负责人**：必填，任务责任人（支持多选）
   - **截止日期**：必填，任务截止时间
   - **优先级**：高、中、低
   - **任务类型**：从字典中选择
   - **状态**：默认"待启动"
3. 点击"创建"

**负责人支持**：
- 单人：选择一个成员
- 多人：点击"选择负责人"按钮，从弹出的搜索框中选择多个成员

### 任务详情

访问路径：`/task/:taskId`

**功能模块**：

#### 1. 基本信息
- 任务名称、描述、状态
- 负责人列表、截止日期
- 项目信息、创建时间

#### 2. 进度汇报
- 汇报当前进度（支持文字描述 + 截图）
- 汇报类型：正常、延期、阻塞
- 汇报时间：自动记录

**注意**：
- 任何负责人都可以进行进度汇报
- 项目负责人可以编辑任务本身（状态、截止日期、负责人）

#### 3. 子任务（待实现）
- 添加子任务
- 子任务状态独立管理

## 待办事项

### 待办列表

访问路径：`/todos`

**功能**：
- 查看所有待办事项
- 筛选待办（按项目、截止日期）
- 搜索待办（按待办名称）
- 创建待办、编辑待办、删除待办
- 标记完成/取消完成

### 统计面板

待办页面提供5个统计块：

| 统计项 | 说明 |
|--------|------|
| **待办逾期** | 截止日期已过且未完成的待办 |
| **待办今日到期** | 截止日期为今天的待办 |
| **启动任务** | 状态为"待启动"的任务数量 |
| **任务进行中** | 状态为"进行中"的任务数量 |
| **已完成待办** | 已完成的待办数量 |

### 创建待办

1. 点击右上角"新建待办"按钮
2. 填写待办信息：
   - **项目**：必填，待办所属项目
   - **待办名称**：必填，待办标识
   - **待办描述**：选填，待办详细说明
   - **负责人**：必填，待办责任人
   - **截止日期**：必填，待办截止时间
   - **优先级**：高、中、低
3. 点击"创建"

**权限说明**：
- 任何成员都可以创建待办
- 项目负责人可以编辑/删除所有待办
- 待办负责人可以编辑/删除自己的待办

### 待办详情

访问路径：`/todo/:todoId`

**功能**：
- 查看待办详情
- 编辑待办信息
- 删除待办
- 标记完成/取消完成

**完成操作**：
- 点击"完成"按钮
- 填写完成说明（选填）
- 确认后待办状态变为"已完成"

## 文档管理

### 文档列表

访问路径：`/documents`

**功能**：
- 查看所有文档（按项目分组）
- 搜索文档（按文档名称、项目名称）
- 筛选文档（按项目、文档类型）
- 上传文档、编辑文档、删除文档

### 创建/上传文档

1. 进入项目详情页
2. 点击"文档"标签页
3. 点击"上传文档"按钮
4. 选择文件：
   - 支持格式：PDF、Word、Excel、PowerPoint、图片
   - 文件大小限制：50MB
5. 填写文档信息：
   - **文档名称**：必填
   - **文档类型**：从字典中选择
   - **文档描述**：选填
6. 点击"上传"

**注意**：
- 文档存储在服务器本地（`data/documents/` 目录）
- 支持在线预览（PDF、图片、Office 文档）
- 删除文档需谨慎，不可恢复

### 文档编辑

1. 点击文档卡片上的"编辑"按钮
2. 在弹出的编辑器中修改内容
3. 保存后自动更新

**编辑器功能**：
- 富文本编辑（加粗、斜体、列表、链接等）
- 图片上传
- 附件上传
- 自动保存

## 里程碑管理

### 里程碑列表

访问路径：`/timeline`

**功能**：
- 查看所有里程碑（按项目分组）
- 搜索里程碑（按里程碑名称、项目名称）
- 筛选里程碑（按项目、状态）
- 创建里程碑、编辑里程碑、删除里程碑

### 创建里程碑

1. 进入项目详情页
2. 点击"里程碑"标签页
3. 点击"新建里程碑"按钮
4. 填写里程碑信息：
   - **里程碑名称**：必填，里程碑标识
   - **里程碑描述**：选填，里程碑详细说明
   - **计划日期**：必填，里程碑计划完成时间
   - **负责人**：必填，里程碑责任人
   - **优先级**：高、中、低
   - **状态**：upcoming（即将到来）、active（进行中）、at_risk（有风险）、completed（已完成）
5. 点击"创建"

### 里程碑状态

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| **upcoming** | 即将到来 | 计划日期 > 今天 |
| **active** | 进行中 | 计划日期在今天或之前，且未完成 |
| **at_risk** | 有风险 | 计划日期在今天或之前，且未完成，但存在延期风险 |
| **completed** | 已完成 | 实际完成日期已记录 |

### 里程碑详情

访问路径：`/timeline/:milestoneId`

**功能**：
- 查看里程碑详情
- 编辑里程碑信息
- 删除里程碑
- 记录完成时间

## 风险管理

### 风险列表

访问路径：`/risks`

**功能**：
- 查看所有风险（按项目分组）
- 搜索风险（按风险名称、项目名称）
- 筛选风险（按项目、等级、状态）
- 创建风险、编辑风险、删除风险
- 风险矩阵可视化

### 创建风险

1. 进入项目详情页
2. 点击"风险"标签页
3. 点击"新建风险"按钮
4. 填写风险信息：
   - **风险名称**：必填，风险标识
   - **风险描述**：必填，风险详细说明
   - **风险等级**：低（1-3）、中（4-6）、高（7-10）
   - **风险责任人**：必填，风险责任人
   - **风险状态**：open（未处理）、in_progress（处理中）、closed（已关闭）
   - **应对措施**：选填，已采取的应对措施
5. 点击"创建"

### 风险矩阵

**功能**：
- 可视化展示风险分布
- X轴：影响程度（1-10）
- Y轴：发生概率（1-10）
- 颜色编码：
  - 🔴 高风险区（影响 ≥7 且 概率 ≥7）
  - 🟡 中风险区（影响 4-6 且 概率 4-6）
  - 🟢 低风险区（影响 ≤3 或 概率 ≤3）

**操作**：
- 点击矩阵中的点，查看风险详情
- 风险点颜色随状态变化自动更新

## 成员管理

### 成员列表

访问路径：`/members`

**功能**：
- 查看所有成员
- 搜索成员（按姓名、邮箱、工号）
- 筛选成员（按角色、部门）
- 创建成员、编辑成员、删除成员
- 修改密码
- 查看成员权限

### 成员角色

| 角色 | 权限 |
|------|------|
| **管理员** | 拥有所有权限（项目管理、任务管理、成员管理等） |
| **项目负责人** | 管理自己负责的项目（创建、编辑、归档审批） |
| **项目成员** | 可以查看项目、任务、文档等，但不可编辑 |
| **普通成员** | 仅可查看自己的任务和待办 |

### 创建成员

1. 点击右上角"新建成员"按钮
2. 填写成员信息：
   - **姓名**：必填
   - **邮箱**：必填，企业微信账号
   - **工号**：选填
   - **部门**：选填
   - **角色**：管理员、项目负责人、项目成员、普通成员
   - **初始密码**：选填，首次登录后可修改
3. 点击"创建"

**注意**：
- 邮箱必须与企业微信账号一致
- 首次登录需通过 SSO 或输入初始密码
- 角色权限在项目维度生效（管理员全局生效）

### 组织架构

访问路径：`/members?tab=org`

**功能**：
- 树形展示部门结构
- 添加部门、编辑部门、删除部门
- 部门级联删除（删除部门时，该部门下的成员自动移至"无部门"）

**操作**：
- 点击"添加部门"按钮，添加一级/二级部门
- 点击部门名称，编辑部门信息
- 点击部门旁边的"删除"按钮，删除部门

## 提醒与通知

### 提醒设置

访问路径：`/reminder-settings`

**功能**：
- 配置待办提醒规则
- 配置任务提醒规则
- 配置项目提醒规则

### 待办提醒规则

**规则类型**：
- **截止前1天提醒**：待办截止前1天发送通知
- **截止前3小时提醒**：待办截止前3小时发送通知
- **截止当日提醒**：待办截止当日发送通知

**操作**：
- 开启/关闭提醒规则
- 设置提醒时间（可自定义）
- 保存后立即生效

### 任务提醒规则

**规则类型**：
- **负责人变更提醒**：任务负责人变更时通知新负责人
- **任务到期提醒**：任务截止前提醒负责人
- **任务状态变更提醒**：任务状态变更时通知相关人员

**操作**：
- 开启/关闭提醒规则
- 设置提醒时间
- 保存后立即生效

### 通知中心

访问路径：`/notifications`

**功能**：
- 查看所有通知
- 筛选通知（按类型、时间）
- 标记已读/未读
- 删除通知

**通知类型**：

| 类型 | 说明 |
|------|------|
| **待办提醒** | 待办截止提醒 |
| **任务提醒** | 任务负责人变更/到期提醒 |

## 权限说明

### 权限模型

项目工作台采用**项目负责制**权限模型：

```
┌─────────────┐
│  管理员      │ ← 全局最高权限
└─────────────┘
      ↓
┌─────────────┐
│  项目负责人  │ ← 项目所有者 + 项目经理
└─────────────┘
      ↓
┌─────────────┐
│  项目成员    │ ← 被分配任务的成员
└─────────────┘
      ↓
┌─────────────┐
│  普通成员    │ ← 仅被分配待办的成员
└─────────────┘
```

### 权限矩阵

| 功能 | 管理员 | 项目负责人 | 项目成员 | 普通成员 |
|------|--------|------------|----------|----------|
| **项目管理** | 全部操作 | 创建、编辑、归档审批 | 查看项目 | 查看项目 |
| **任务管理** | 全部操作 | 创建、编辑、删除 | 查看、汇报 | 查看、汇报 |
| **待办管理** | 全部操作 | 创建、编辑、删除 | 创建、编辑、删除自己的待办 | 创建、编辑、删除自己的待办 |
| **文档管理** | 全部操作 | 上传、编辑、删除 | 上传、编辑、删除自己的文档 | 上传、编辑、删除自己的文档 |
| **里程碑管理** | 全部操作 | 创建、编辑、删除 | 查看、汇报 | 查看、汇报 |
| **风险管理** | 全部操作 | 创建、编辑、删除 | 查看、汇报 | 查看、汇报 |
| **资源管理** | 全部操作 | 创建、编辑、删除 | 查看 | 查看 |
| **成员管理** | 全部操作 | 查看成员列表 | 查看成员列表 | 查看成员列表 |
| **组织架构** | 全部操作 | 查看组织架构 | 查看组织架构 | 查看组织架构 |

### 关键权限说明

#### 项目负责制核心原则

1. **项目负责制**：
   - 项目负责人（ownerId 或 manager）对项目拥有完全控制权
   - 管理员对所有项目拥有完全控制权

2. **任务可见性隔离**：
   - 项目成员只能查看自己被分配的任务
   - 项目成员可以查看项目下所有任务的时间线
   - 项目成员可以查看项目下所有风险、里程碑、文档

3. **待办隔离**：
   - 项目成员只能查看/编辑/删除自己创建的待办
   - 待办负责人可以查看/编辑/删除自己的待办
   - 项目负责人可以查看/编辑/删除所有待办

4. **文档隔离**：
   - 项目成员只能查看/编辑/删除自己创建的文档
   - 文档负责人可以查看/编辑/删除自己的文档
   - 项目负责人可以查看/编辑/删除所有文档

## 常见问题

### Q1：忘记密码怎么办？

**A**：请联系管理员重置密码。管理员可以在"成员管理"页面为成员重置密码。

### Q2：如何切换账号？

**A**：退出登录后，使用新的企业微信账号重新登录。

### Q3：项目归档后如何恢复？

**A**：请联系管理员，管理员可以在"项目管理"页面手动恢复已归档的项目。

### Q4：任务负责人可以修改任务状态吗？

**A**：项目负责人可以修改任何任务的状态。任务负责人只能汇报进度，不能直接修改任务状态（如从"进行中"改为"已完成"）。

### Q5：如何批量导出数据？

**A**：当前版本不支持批量导出。如需导出数据，请联系管理员手动导出。

### Q6：如何添加新成员？

**A**：管理员可以在"成员管理"页面创建新成员。新成员会自动同步企业微信成员信息（如果启用同步）。

### Q7：待办可以设置重复提醒吗？

**A**：当前版本不支持重复提醒。待办仅支持单次提醒（截止前/当日提醒）。

### Q8：如何删除项目？

**A**：
1. 项目负责人发起归档申请
2. 管理员审批通过后，项目归档
3. 如需彻底删除，请联系管理员（删除后不可恢复）

### Q9：任务进度汇报后，任务状态会自动更新吗？

**A**：不会。进度汇报仅记录进度信息，任务状态仍需项目负责人手动更新。

### Q10：如何设置任务提醒？

**A**：进入"提醒设置"页面，配置任务提醒规则。提醒规则保存后立即生效。
