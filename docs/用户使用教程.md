## 快速开始

### 系统要求
- 现代浏览器（Chrome、Edge、Firefox、Safari）
- 稳定的网络连接

### 启动方式

**本地开发环境**：
```bash
# 后端
cd server
node simple-server.js

# 前端（新终端）
cd D:\AI\project-workbench
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5173
```

**生产环境**：
```bash
cd ~/xmgl/project-workbench
bash scripts/server-run.sh
```

访问：http://localhost:5173（本地）/ http://172.17.80.141:5173（服务器）

## 登录系统

### 方式一：SSO 登录（推荐）

1. 点击登录页的"企微登录"按钮
2. 跳转到企业微信授权页面
3. 授权后自动跳转回系统，完成登录

**优点**：
- 无需记忆密码
- 自动同步企业成员信息
- 安全性高（HttpOnly Cookie）

### 方式二：账号密码登录

1. 输入企业微信账号（邮箱）
2. 输入密码
3. 点击"登录"

**注意**：
- 密码由管理员在"成员管理"页面设置
- 首次登录后建议修改密码

## 仪表盘

### 功能概览

仪表盘是系统的首页，提供以下核心信息：

| 统计项 | 说明 |
|--------|------|
| **任务总数** | 项目中所有任务的数量（含完成/未完成） |
| **待达成里程碑** | 状态为 upcoming 或 at_risk 的里程碑数量 |
| **待处理风险** | 状态非 closed 的风险数量 |
| **团队成员** | 被分配任务或待办的人员去重计数 |
| **未完成事项** | 进行中任务 + 待启动任务 + 未完成待办 |

### 快捷操作

- 点击"未完成事项"卡片 → 跳转到待办与提醒页面
- 点击"团队成员"卡片 → 跳转到成员管理页面
- 点击"项目统计"卡片 → 查看各项目进度
- 点击"任务状态图表" → 查看任务分布
- 点击"进度对比" → 查看项目完成率对比

## 项目管理

### 项目列表

访问路径：`/projects`

**功能**：
- 查看所有项目（按创建时间倒序）
- 搜索项目（按项目名称）
- 创建新项目
- 查看项目详情
- 归档项目（需审批）

### 创建项目

1. 点击右上角"新建项目"按钮
2. 填写项目信息：
   - **项目名称**：必填，项目标识
   - **项目类型**：从字典中选择（如"研发项目"、"市场活动"）
   - **项目阶段**：从字典中选择（如"规划中"、"执行中"、"已交付"）
   - **负责人**：必填，项目所有者
   - **项目描述**：选填，项目背景和目标
3. 点击"创建"

**注意**：
- 负责人必须是系统成员
- 创建后自动生成项目编号（XM_xxx）

### 多级子项目

项目支持**最多 4 级层级**（主项目 L0 + 3 级子孙）。

#### 创建子项目

1. 在"项目管理"列表页，展开一个主项目，点击其行末的 **"+"** 按钮
2. 弹出新建项目表单，"隶属项目"会自动带出点击的主项目
3. 填写子项目名称（编号自动生成），保存即可

**编号规则（层级编号）**：
- 主项目：全局顺序 `XM_001`、`XM_002`…
- 子项目：父编号 + `.` + 同级序号（单数字），逐级追加
  - 例：`XM_008` → 第一个子项目 `XM_008.1` → 其第一个子项目 `XM_008.1.1`
  - 同级新建时自动取下一个序号（如已有 `XM_008.1`、`XM_008.2`，新建则为 `XM_008.3`）
- 切换"隶属项目"时，编号自动按新父编号重算；编辑已有项目时编号不变

**约束**：
- 子项目自动继承父项目的负责人、所有者、颜色、起止区间
- 已达最大层级（L3）时无法再建子项目
- 不能把项目挂到自己的子孙下（防环）

#### 子项目树展示

- 项目管理页按 `L0 / L1 / L2 / L3` 徽标 + 逐级缩进展示层级
- "直属任务"仅显示挂在本项目 id 上的任务；子项目的任务显示在对应子项目行下
- 支持跨层级搜索（名称/编号/负责人），命中项 + 祖先链自动展开定位

### 项目合并与撤销

主项目可以**合并**到另一个主项目（把自身及全部子孙的任务/待办/文档/里程碑/风险/资源一次性迁到目标），合并后源项目隐藏。

#### 发起合并

1. 进入项目详情页（或项目管理页），点击"合并项目"按钮
2. 选择目标主项目
3. 预览：系统显示将要迁移的实体数量（任务、待办、文档、里程碑、风险、资源）
4. 选择迁移策略后确认执行

#### 撤销合并

- 合并后 24 小时内可"撤销合并"：源项目复活、实体归属还原、子项目挂接还原
- 超过 24 小时后不可撤销
- 管理员与目标项目所有者可操作撤销

**注意**：
- 合并只发生在两个主项目之间（子项目不能合并到主项目之外）
- 合并是后端原子操作，要么全部成功、要么全部回滚
- 撤销窗口 24 小时，请在此时间内检查

### 项目下拉筛选

- 项目管理页左上角"全部项目"下拉：列出**所有活跃主项目**（不限状态，含待启动/进行中/已完成），选项显示"编号 名称"
- 选中某主项目后，下方列表仅显示该项目 + 其全部子项目（子树）
- 点击"← 返回全部项目"可清空筛选
- 支持"跨层级搜索项目（名称/编号/负责人）"输入框做全树模糊匹配


### 项目详情

访问路径：`/projects/:id`

**功能模块**：

#### 1. 基本信息
- 项目名称、编号、类型、阶段
- 负责人、创建时间、归档状态
- 项目描述

#### 2. 任务时间线
- 查看任务列表（按截止日期排序）
- 添加任务、编辑任务、删除任务
- 任务进度汇报
- 任务状态：待启动 → 进行中 → 评审中 → 已完成/已阻塞

#### 3. 里程碑
- 查看里程碑列表
- 添加里程碑、编辑里程碑、删除里程碑
- 里程碑状态：upcoming（即将到来）、active（进行中）、at_risk（有风险）、completed（已完成）

#### 4. 风险
- 查看风险列表
- 添加风险、编辑风险、删除风险
- 风险等级：低（1-3）、中（4-6）、高（7-10）
- 风险状态：open（未处理）、in_progress（处理中）、closed（已关闭）

#### 5. 文档
- 查看项目文档列表
- 上传文档、编辑文档、删除文档
- 文档类型：技术文档、会议纪要、需求文档、其他

#### 6. 资源
- 查看项目资源列表
- 添加资源、编辑资源、删除资源
- 资源类型：人力、设备、资金、其他

### 项目归档审批

**触发条件**：
- 项目负责人发起归档申请
- 管理员审批通过

**流程**：

1. **项目负责人**：
   - 进入项目详情页
   - 点击右上角"归档项目"按钮
   - 填写归档原因
   - 提交申请

2. **管理员审批**：
   - 进入"项目管理"页面
   - 找到待审批项目
   - 点击"审批"按钮
   - 选择"通过"或"驳回"
   - 如果通过，项目归档；如果驳回，项目恢复

3. **项目归档后**：
   - 项目不在项目列表中显示
   - 项目相关数据（任务/文档/风险）仍然保留
   - 如需恢复，需管理员手动操作

### 任务计划变更与废止

任务在执行过程中可能需要调整计划或取消，系统提供受控的变更与废止机制。

#### 计划变更（编辑延期）

1. 在任务卡片悬停点击"编辑"（铅笔）按钮，打开任务编辑弹窗
2. 修改"截止日期"后，若与原日期不同，表单会要求填写**变更原因**（必填，不填无法保存）
3. 保存后系统记录变更历史（原计划结束日期 → 新日期 + 原因）
4. 时间线甘特图在原计划结束日期绘制**蓝色小竖线**，悬停显示"计划变更：<原因>"

#### 废止任务

仅"进行中"任务可发起废止（任务负责人或项目负责人均可）：

1. 任务卡片悬停点击"废止"（红色禁止）按钮 → 填写**废止理由**（必填）→ "提交申请"
2. 提交后弹窗关闭，任务进入"待评审"（卡片显示"待评审"徽标，废止按钮消失）
3. 项目负责人评审通过后：任务标记"已废止"、状态变"已完成"、从"进行中"移到"已完成"栏，编辑/废止按钮均不再显示
4. 时间线中计划线变**深灰**并悬停显示废止原因；点击该任务条弹出的弹窗中"新增待办 / 新增进度汇报 / 添加文档"置灰不可用，并显示废止原因横幅

#### 删除限制与评审锁定

- **删除**：仅"待启动"任务显示删除按钮；进行中及之后状态被锁定，须走废止流程
- **评审中锁定**：处于"评审中"的任务不可编辑，需先撤回评审

#### 状态流转（含变更 / 废止）

```
待启动 → 进行中 → 评审中 → 已完成
   │          │          ↑
   │          │          └─ 评审通过
   │          └─ 进行中可发起「废止」→ 评审通过 → 已完成（标记已废止）
   └─ 待启动可直接删除
已阻塞（任意非终态可标记，解除后回到原状态）
```

## 里程碑与时间线

### 里程碑列表

访问路径：`/timeline`

**功能**：
- 查看时间线甘特图 + 里程碑列表
- 筛选里程碑（按项目、状态）
- 创建里程碑、编辑里程碑、删除里程碑
- 项目筛选下拉默认只显示**主项目**（选项为"编号 名称"），勾选"含子项目"后才展开显示该主项目下的子项目

### 甘特图与项目族色

时间线甘特图按主项目家族着色，便于快速区分不同主线：

**项目汇总行底色（族色 + 层级色阶）**：
- 同一主项目家族（主项目 + 子项目）共享同一色系，色系 4 档循环（淡灰 / 淡绿 / 淡蓝 / 淡桔）
- 主项目汇总行用**基础色**（最深）
- 子项目每深一级**逐级变浅一档**，肉眼可辨，但仍比任务底色深
  - 如桔色家族：主项目 `#f59e0b` → L1 较浅 → L2 更浅 → L3 最浅（仍比任务底色深）

**任务行底色（白 / 浅交替）**：
- 同一项目下的任务行严格交替：第 1 个白色、第 2 个家族最浅色（30% 深度）、第 3 个白色……
- 最浅色明显比项目汇总行浅，不会与子项目行混淆

**图例**：

| 图例 | 含义 |
|------|------|
| 蓝色横线 | 计划时间（任务起止） |
| 蓝色短竖线 | 计划变更标记（改期时在原计划结束日期处，悬停显示变更原因） |
| 深灰色横线 | 已废止任务的计划线（悬停显示废止原因） |
| 绿色实心圆 | 任务启动点 |
| 绿色横线 | 实际进度 |
| 绿色短竖线 | 汇报节点 |
| 绿色实心方块 | 已完成 |
| 红色横线 | 超出计划 |
| 红虚线 | 今天 |

**交互**：

## 权限说明

### 权限模型

项目工作台采用**项目负责制**权限模型：

```
┌─────────────┐
│  管理员      │ ← 全局最高权限
└─────────────┘
      ↓
┌─────────────┐
│  项目负责人  │ ← 项目所有者 + 项目经理
└─────────────┘
      ↓
┌─────────────┐
│  项目成员    │ ← 被分配任务的成员
└─────────────┘
      ↓
┌─────────────┐
│  普通成员    │ ← 仅被分配待办的成员
└─────────────┘
```

### 权限矩阵

| 功能 | 管理员 | 项目负责人 | 项目成员 | 普通成员 |
|------|--------|------------|----------|----------|
| **项目管理** | 全部操作 | 创建、编辑、归档审批 | 查看项目 | 查看项目 |
| **任务管理** | 全部操作 | 创建、编辑、删除 | 查看、汇报 | 查看、汇报 |
| **待办管理** | 全部操作 | 创建、编辑、删除 | 创建、编辑、删除自己的待办 | 创建、编辑、删除自己的待办 |
| **文档管理** | 全部操作 | 上传、编辑、删除 | 上传、编辑、删除自己的文档 | 上传、编辑、删除自己的文档 |
| **里程碑管理** | 全部操作 | 创建、编辑、删除 | 查看、汇报 | 查看、汇报 |
| **风险管理** | 全部操作 | 创建、编辑、删除 | 查看、汇报 | 查看、汇报 |
| **资源管理** | 全部操作 | 创建、编辑、删除 | 查看 | 查看 |
| **成员管理** | 全部操作 | 查看成员列表 | 查看成员列表 | 查看成员列表 |
| **组织架构** | 全部操作 | 查看组织架构 | 查看组织架构 | 查看组织架构 |

### 关键权限说明

#### 项目负责制核心原则

1. **项目负责制**：
   - 项目负责人（ownerId 或 manager）对项目拥有完全控制权
   - 管理员对所有项目拥有完全控制权

2. **任务可见性隔离**：
   - 项目成员只能查看自己被分配的任务
   - 项目成员可以查看项目下所有任务的时间线
   - 项目成员可以查看项目下所有风险、里程碑、文档

3. **待办隔离**：
   - 项目成员只能查看/编辑/删除自己创建的待办
   - 待办负责人可以查看/编辑/删除自己的待办
   - 项目负责人可以查看/编辑/删除所有待办

4. **文档隔离**：
   - 项目成员只能查看/编辑/删除自己创建的文档
   - 文档负责人可以查看/编辑/删除自己的文档
   - 项目负责人可以查看/编辑/删除所有文档

## 常见问题

### Q1：忘记密码怎么办？

**A**：请联系管理员重置密码。管理员可以在"成员管理"页面为成员重置密码。

### Q2：如何切换账号？

**A**：退出登录后，使用新的企业微信账号重新登录。

### Q3：项目归档后如何恢复？

**A**：请联系管理员，管理员可以在"项目管理"页面手动恢复已归档的项目。

### Q4：任务负责人可以修改任务状态吗？

**A**：项目负责人可以修改任何任务的状态。任务负责人只能汇报进度，不能直接修改任务状态（如从"进行中"改为"已完成"）。

### Q5：如何批量导出数据？

**A**：当前版本不支持批量导出。如需导出数据，请联系管理员手动导出。

### Q6：如何添加新成员？

**A**：管理员可以在"成员管理"页面创建新成员。新成员会自动同步企业微信成员信息（如果启用同步）。

### Q7：待办可以设置重复提醒吗？

**A**：当前版本不支持重复提醒。待办仅支持单次提醒（截止前/当日提醒）。

### Q8：如何删除项目？

**A**：
1. 项目负责人发起归档申请
2. 管理员审批通过后，项目归档
3. 如需彻底删除，请联系管理员（删除后不可恢复）

### Q9：任务进度汇报后，任务状态会自动更新吗？

**A**：不会。进度汇报仅记录进度信息，任务状态仍需项目负责人手动更新。

### Q10：如何设置任务提醒？

**A**：进入"提醒设置"页面，配置任务提醒规则。提醒规则保存后立即生效。

### Q11：子项目编号是怎么生成的？

**A**：主项目用全局顺序号（`XM_001`、`XM_002`…）；子项目引用父编号加同级序号，如 `XM_008` 的第一个子项目是 `XM_008.1`，它的第一个子项目是 `XM_008.1.1`。切换隶属项目时编号自动重算。最多 4 级（主项目 + 3 级子孙）。

### Q12：为什么甘特图里子项目颜色和主项目不一样？

**A**：同一主项目家族共享一个色系，主项目用最深的基色，子项目每下一级变浅一档，方便按层级区分。子项目的底色仍比任务行底色深，不会混淆。

### Q13：项目合并后能撤销吗？

**A**：能。合并后 24 小时内可"撤销合并"，源项目复活、实体归属与子项目挂接还原；超过 24 小时则不可撤销。

### Q14：时间线/任务页的项目下拉为什么只显示主项目？

**A**：为避免下拉过长，默认只列主项目。勾选"含子项目"后才会展开当前主项目下的子项目。项目管理页的下拉则列所有活跃主项目（不限状态）。

### Q15：为什么"进行中"任务不能直接删除？

**A**：防误删设计——删除按钮只在"待启动"状态显示。进行中及之后状态被锁定，必须走"废止"流程（任务负责人或项目负责人发起 → 项目负责人审批通过），才从进行中移除并归入已完成（标记已废止）。

### Q16：编辑任务改了"截止日期"，为什么必须填变更原因？

**A**：系统会记录改期轨迹：编辑任务时若截止日期与原日期不同，强制要求填写变更原因，并把"原计划结束日期 → 新日期 + 原因"记入历史；时间线甘特图在原计划结束日期画蓝色小竖线，悬停显示原因，便于复盘。

### Q17：任务废止通过后去哪了？状态会变吗？

**A**：会变。审批通过后任务标记"已废止"、状态变"已完成"，从"进行中"栏移到"已完成"栏，编辑/废止按钮消失；时间线计划线变深灰并悬停显示原因；点击该任务弹出的弹窗中"新增待办 / 新增进度汇报 / 添加文档"置灰不可用，并显示废止原因横幅。
